## 🚀 UPLOAD TO GITHUB

### Step 1: Create Repository
1. Go to github.com
2. Click + → New repository
3. Name: `mhms-oral-screening`
4. Visibility: **Private** (recommended)
5. DO NOT initialize with README
6. Click Create repository

### Step 2: Upload Files
1. On repo page, click "uploading an existing file"
2. Drag all your files/folders into the upload area
3. Click "Commit changes"

### Step 3: Deploy to GitHub Pages
See README.md for deployment instructions.

## ⚠️ IMPORTANT

- Keep repository **PRIVATE** (handles health data)
- Never commit `.env` file (only `.env.example`)
- Never commit `node_modules/` folder
- The `.gitignore` file handles this automatically
